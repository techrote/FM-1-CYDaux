## Native touchscreen editor (successor candidate)
Open the existing CYDaux evaluator and choose **Open Chronomorph native editor**. Enable sound, then tap START. Three lanes expose independent full 16-bit masks, length 1–16, active step, cycle and actual local clock phase; BPM/warp/variation controls and three preset scenes are directly mapped to the pinned C core. Tap STOP or Panic for immediate release; reset and scene selection stop and reset the engine. Pattern/length/parameter edits preserve clock phase except the core's documented length modulo adjustment. A shorter lane clears truncated bits. The same native simulator process, Canvas drawing primitives, HTTP PCM stream and audio lease/watchdog are used; this editor is not installed in the ESP32 firmware and not a new CY1 profile or FM-1 transport claim. Use Return to firmware profiles to leave the editor. One local evaluator session at a time. Physical HOLD and independent QA remain.

## Normalized macro performance page

In the native editor tap **MACROS** above the lane grid. Three full-width sliders provide BPM 40–220, warp −60..60 and variation 0–100 via the exact GEN normalized knob contract; the applied integer and canonical 0–127 code are shown separately. Drag captures only its original slider, even across START/STOP; cancellation retires capture. **PATTERN** returns to the full-width pattern editor and precise ±5 controls. Edits preserve running state, clock phase and patterns; Start/Stop/Reset remain accessible. The canonical code is not an exact representation of every integer BPM, and opening the page does not quantize an existing local value.
